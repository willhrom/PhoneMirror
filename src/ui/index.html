Get the Phone Mirror app

No developer settings needed. Your phone and this laptop just need the same Wi-Fi.

  1. Scan this with your phone's camera to download the app.
  2. Open the downloaded file to install it. If asked, allow installs from your browser.
  3. Open Phone Mirror and tap Share screen. Your phone appears here under My phones.
  4. To use your mouse and keyboard on the phone, tap Turn on in Accessibility in the app.

Set up your phone

You only need to do this once.

  1. Open Settings › About phone (Samsung: About phone › Software information).
  2. Tap Build number 7 times until it says you're a developer.
  3. Go to Settings › System › Developer options and turn on USB debugging.
  4. Plug in, unlock the phone, and tap Allow (tick Always allow from this computer).

Phone not showing up?

  1. Unlock the phone and look for an "Allow USB debugging?" prompt. Tap Allow.
  2. Use a data cable. Some cables only charge. Try another USB port too.
  3. Pull down the notification shade, tap the USB notification, and choose File transfer.
  4. Make sure USB debugging is still on in Developer options.
  5. Samsung, Motorola, and some others need their USB driver on Windows. Search "[your brand] USB driver".
  6. Still nothing? In Developer options tap Revoke USB debugging authorizations, then replug.
